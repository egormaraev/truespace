# TrueSpace - Образовательная платформа с промо-кодами

TrueSpace - это современная образовательная платформа для хостинга видеоуроков с минималистичным дизайном в темно-белой цветовой схеме. Платформа предоставляет доступ к видеоурокам только при вводе специального промо-кода.

## Основные функции

- Система аутентификации пользователей (регистрация, вход, восстановление пароля)
- Доступ к видеоурокам только при вводе специального промо-кода
- Личная страница профиля пользователя
- Система для избранных и сохраненных уроков/курсов
- Функционал поиска с фильтрами и категориями
- Административная панель для управления контентом
- Адаптивный дизайн для всех устройств

## Технический стек

- **Frontend**: React с TypeScript, Tailwind CSS
- **Backend**: Next.js API Routes
- **База данных**: MongoDB
- **Хостинг**: Render
- **Хранение видео**: Интеграция с облачным хранилищем (AWS S3)

## Требования

- Node.js 18.x или новее
- MongoDB
- Аккаунт Render для деплоя
- Аккаунт AWS для хранения видео (опционально)

## Установка и запуск

### Локальная разработка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/truespace.git
   cd truespace
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Создайте файл `.env.local` в корне проекта и добавьте следующие переменные окружения:
   ```
   MONGODB_URI=your_mongodb_connection_string
   NEXTAUTH_SECRET=your_nextauth_secret_key
   NEXTAUTH_URL=http://localhost:3000
   JWT_SECRET=your_jwt_secret_key
   S3_ACCESS_KEY=your_s3_access_key
   S3_SECRET_KEY=your_s3_secret_key
   S3_BUCKET_NAME=your_s3_bucket_name
   S3_REGION=your_s3_region
   ```

4. Запустите сервер разработки:
```bash
npm run dev
```

5. Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### Деплой на Render

1. Создайте новый Web Service на Render и выберите репозиторий с проектом.

2. Настройте сервис:
   - **Name**: truespace
   - **Environment**: Node
   - **Build Command**: `npm install && npm run build`
   - **Start Command**: `npm start`

3. Добавьте необходимые переменные окружения в разделе Environment.

4. Нажмите кнопку "Create Web Service".

## Система промо-кодов

Платформа использует систему промо-кодов для предоставления доступа к курсам:

1. Администратор создает промо-коды через админ-панель
2. Каждый промо-код может быть привязан к определенным курсам
3. Пользователи активируют промо-коды на странице профиля или при попытке доступа к курсу
4. После активации промо-кода пользователь получает доступ к соответствующим курсам
